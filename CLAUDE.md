@AGENTS.md

This project is intended to be CDJ-3000 simulator with a learning mode so that aspiring DJs can learn how to use the equipment. The product manual is available [here](https://downloads.support.alphatheta.com/manuals/dj-players/CDJ-3000/CDJ-3000_DRI1586A_manual).

I want this simulator to be as similar as possible to the phsyical product. You can see images and product details [here](https://www.pioneerdj.com/en/product/dj-players-turntables/cdj-3000/). Make sure to do a typical DJ setup with two CDJs on either side of a [DJM-V10](https://www.pioneerdj.com/en/product/dj-mixers/djm-v10/).


I plan on supporting web, android, ios platforms using expo. Later on a desktop app would be great.
